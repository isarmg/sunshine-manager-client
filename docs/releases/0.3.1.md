# Sunshine Client 0.3.1

与 Sunshine Manager 0.12.1 配套，使用 sunshine-client-protocol 0.4.0；设备连接继续使用
sunshine-management/3 与 /sunshine-client/v3/。从 Client 0.3.0 升级保留本机状态和配对账户，无需重新配对。

## 更改

- 新增 SaveConfig：执行时读取本机完整配置，将页面提供的全部可管理项目直接覆盖，缺省项目删除；
  保留本机私有、未开放远程管理和其他平台的设置，不核对页面旧修订。
- 保存前保护原配置备份，持久化目标意图；单次 POST 后完整读回，失去回执时核对事实，不重复写入。
- 原有 PatchConfig 保留完整修订校验。
- 新增待 Moonlight 配对请求查询，支持 Sunshine 不带 status 字段的 GET /api/pin 响应。
- PIN 提交明确失败时报告 pairing_failed；不确定结果沿用持久记录，避免自动重发。

界面进入和手动刷新时才替换配置编辑快照。保存不会自动重启，也不代表运行时串流效果已验证。
测试使用固定 Sunshine API 的本机 HTTPS 替身及隔离 Manager/Client 闭环，不代替真实设备配对和串流验收。
本说明描述源码版本，不表示原生安装包已发布。
