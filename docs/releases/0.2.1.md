# Sunshine Client 0.2.1

- 所有交互字段迁移到 Foundation 0.9.10 的原生控制终端输入；Unix 不再调用 `stty`，Windows 不再启动 PowerShell。
- Manager 授权码和 Sunshine 密码明确提示隐藏输入，采用字段级长度上限、统一截止时间和自动清零缓冲区。
- 普通 `setup` 发现未完成的 Manager 配对时会询问是否继续；默认重新读取授权码，并可在保留同一 pending 身份的情况下更新待提交配置。
- 超时、取消、缺少终端与终端模式故障返回独立错误码；继续只支持当前 v2 协议与当前 Bootstrap 格式。
- 本机 Sunshine 连接固定为 HTTPS 回环 IP、禁用代理和重定向，并继续用 Sunshine API 凭据认证；删除证书发现、读取、保存、固定、系统信任与指纹诊断代码。Manager 连接仍严格校验 TLS 身份和设备凭据。
- Manager 配对 HTTP 错误按入口缺失、方法拒绝、升级要求、授权拒绝和临时不可用分别报告；只有结构化 `unsupported_client_protocol` 才报告协议不兼容。
