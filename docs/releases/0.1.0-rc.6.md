# Sunshine Client 0.1.0-rc.6

重复安装现在可覆盖程序文件、修复服务，并在保留状态的卸载后重新安装。Windows、Linux、macOS 安装脚本保留设备身份、Sunshine 凭据及任务执行记录；活动服务在替换完成后恢复。Linux DEB 支持保留状态的版本升级，Windows MSI 建立稳定产品升级标识并支持强制文件修复。

新增 [Windows、Ubuntu 和 macOS Apple Silicon 配置指南](../platform-setup.md)，包含实际安装命令、服务启动、配置路径、HTTPS 信任和故障日志。归档中也包含此指南。

协议和持久状态格式保持不变。安装文件未签名、未公证；只发布 Apple Silicon macOS 包。CI 验证原生服务及覆盖安装，真实 Sunshine 设备联调和断电重启后运行需要对应设备验收。
