# Sunshine Client 0.1.1

The Client now consumes Client Foundation 0.9.0 for the complete common CLI/service lifecycle and authenticated local-status channel. Sunshine-specific code declares its commands, native service identity and paths, and retains provisioning, certificate trust, local Sunshine access, task execution, and result confirmation.

`credentials update` can rotate an explicitly pinned Sunshine certificate or deliberately return to system trust without replacing the Manager binding. Omitted trust fields preserve the current mode; conflicting trust inputs fail before state is changed.

Pairing now binds the Manager identity to Sunshine's native certificate material while keeping the Server authorization code out of command arguments and logs. Server-side authorization rotation invalidates the old Client binding and requires an explicit re-pair.

Linux, Windows, and macOS packages are rebuilt and verified from the tagged source. Native packages remain unsigned and include source-bound manifests and checksums.
