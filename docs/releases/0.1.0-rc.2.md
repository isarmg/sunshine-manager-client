# Sunshine Client v0.1.0-rc.2

本次为安装包与 Windows 托盘的预发布版本，独立于 Sunshine Manager Server 发行。

## 下载与安装

- Windows x86_64：下载 `sunshine-client-0.1.0-rc.2-windows-x64.msi`，双击按向导安装。安装结束打开托盘，选择“配对设置”，填写 Manager 提供的配对信息、可信 CA 和本机 Sunshine 凭据。
- Ubuntu 24.04 x86_64：下载 `sunshine-client_0.1.0~rc2_amd64.deb`，运行 `sudo apt install ./sunshine-client_0.1.0~rc2_amd64.deb`，再运行 `sudo sunshine-client-setup` 完成交互式配对。
- ZIP/tar.gz 保留给手动部署使用；不包含图形安装体验，普通 Windows 用户请选择 MSI。

Windows 托盘登录自启，可查看后台服务状态和打开配对设置；退出托盘不停止后台服务。
服务状态不等于 Client 在线、Sunshine 可达或配置生效；这三项仍在 Manager 分别核验。
Windows 配对需要本机管理员授权。默认不允许 Sunshine 重启，可在本机显式授权；Manager 仍须逐次确认。

## 安全与范围

- 不更改 Sunshine–Moonlight 串流链路，不安装 Sunshine，不开放额外入站端口，不提供任意脚本执行。
- 本机 Sunshine 凭据只保存在受保护的本机状态中。安装不关闭 TLS 验证，仍需提供可信证书。
- 卸载保留设备身份、凭据与执行去重记录；退役时须在 Manager 撤销设备。
- 不支持覆盖旧安装或升级旧状态；升级和恢复遵守 sarmg-upgrade 的职责边界。
- Windows MSI **没有 Authenticode 签名**，可能出现 SmartScreen 提示。校验和不等于发布者签名。
- MSI 内部数字版本为 `0.1.0`；完整候选版本、源码 SHA 和安装包校验和见附件 manifest，客户端 `--version` 同样绑定源码。

## 验证范围

发布附件仅取自当前标签的双平台成功 CI：Rust 测试、严格 TLS 测试、MSI/DEB 构建及真实安装、初始化、服务重启、重复初始化拒绝、卸载保留状态；Windows 另验证图形配置入口与托盘退出不影响服务。

CI 原生基线为 Windows Server 2025 x86_64 和 Ubuntu 24.04 x86_64。本次不是其他 Windows 桌面版本的安装实测，也不宣称完成本版本的真实 Sunshine 重启验收。
协议仍为 `sunshine-management/1`，Sunshine 固定适配官方 `v2026.516.143833`，其他 Sunshine 版本会被拒绝。
