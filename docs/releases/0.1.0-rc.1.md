# Sunshine Manager Client 0.1.0-rc.1

独立 Client 仓库首次候选发行，提供 Linux x86_64 GNU 和 Windows x86_64 MSVC 安装归档及 SHA-256 校验文件。Windows 包未进行 Authenticode 签名；Linux 构建基线为 Ubuntu 24.04（glibc 2.39）。安装、自启动、卸载和本机凭据配置见归档内 README 与 deploy 目录。

Client 通过主动建立的 WSS 管理连接接收任务，只管理本机 Sunshine，不转发视频、不改变 Sunshine–Moonlight 串流链路。协议为 sunshine-management/1，本版只适配官方 Sunshine v2026.516.143833，不承诺兼容其他版本或旧 Client 状态。

发布构建运行原生 Linux/systemd、Windows/MSVC Service 安装生命周期检查、Rust 测试和 HTTPS/WSS 隔离测试。每份安装归档携带源码提交、版本和文件校验清单。

此版本仍为预发布：拆仓后的闭环验收使用 HTTPS 测试服务；此前真实 Windows Sunshine 验收不等于本提交的双平台真实服务验收，真实 Linux Sunshine 验收尚未完成。配置保存、等待重启与运行时生效分别报告；不能确认的重启结果仍标记 unknown，不会盲目重试。

Server 由 isarmg/sunshine-manager-server 独立发行。本发布不包含 Server、不提供迁移或自动升级。
