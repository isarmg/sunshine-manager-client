# xscc 1.0.0

[发行页](https://github.com/isarmg/xscc/releases/tag/v1.0.0)提供 Windows x64 MSI、Linux x86_64 DEB 和 macOS arm64 未签名 PKG。原生包带独立 manifest 与 .sha256，同时提供二进制归档。

本版管理本机 Sunshine v2026.914.233613，使用 xscs-management/1 和 xscs-task/1；Windows/Ubuntu 支持固定服务控制，macOS 在本机管理服务。

## 开始使用

[安装并配对](../platform-setup.md) → [确认运行](../usage.md) → [日常维护](../administration.md)。当前发布资产的源码身份由对应 manifest / version 输出确认，main 的后续提交不自动进入现有包。

## 验证范围

平台原生构建、安装器、服务生命周期、网络协议与Sunshine 实机测试分别记录。协议夹具和编译通过不等于全部设备实测；在目标主机按安装页完成业务验证。开发命令见[开发指南](../development.md)。
