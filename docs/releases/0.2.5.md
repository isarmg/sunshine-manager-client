# Sunshine Manager Client 0.2.5

- Windows MSI 改用明确的自定义安装页，允许选择程序安装目录，并分别选择是否保留旧配置/配对凭据与旧执行日志；两类状态默认保留。
- 用户取消保留时，MSI 只清理对应状态类别，并在发现链接、异常文件类型或超出安全边界时终止安装、保留原数据。
- 交互式 Windows 安装始终显示完成页或失败页；无人值守安装继续通过 `msiexec` 退出码和日志报告结果。
- 旧账户状态与重要执行日志继续使用 `pairing_state_incompatible` 和 `important_state_incompatible` 两条独立恢复路径。
