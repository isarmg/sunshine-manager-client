# Sunshine Client 0.1.4

- Manager 配对、注册、诊断和 WebSocket 连接改用标准系统 DNS、代理与 WebPKI TLS 行为。
- 删除共享 DNS/Fake-IP/IP 地址策略和自定义 Manager WSS Connector，同时保留 HTTPS、WSS、同源和响应大小限制。
- 本机 Sunshine 连接继续绕过代理，并保留精确证书固定、Basic Auth 和本地接口限制。
- 持久配置、设备身份和任务日志格式保持不变。
- 本地自签名 HTTPS 验收继续自动执行；需要公网受信任证书的 Manager WSS 正向验收保留为独立环境门禁。
