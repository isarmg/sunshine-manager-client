# Sunshine Manager Client 0.2.3

- 旧版 v1 状态现在明确返回 `state_schema_unsupported`，不执行隐式迁移，并与损坏文档错误保持区分。
- Sunshine 版本诊断包含检测值、来源和支持范围；`setup` 将本机 Sunshine 预检作为独立步骤报告。
- 健康检查统一使用 `/healthz`；Windows 服务失败使用稳定的服务专用错误码，不再误报系统错误 1。
- 凭据或协议被拒绝时记录终止原因，并提示使用 `pair --replace` 恢复配对。
- macOS 安装只部署并注册服务；Client Foundation 更新至 `0.9.14`，Windows 提权等待具有明确超时。

本版本不包含安装包签名或公证，也不新增旧版本状态迁移。
