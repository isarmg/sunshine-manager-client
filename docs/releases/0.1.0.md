# Sunshine Client 0.1.0

The first stable release carries forward the verified first-run setup behavior from rc.10. Pairing-state validation, service quiescing, installer flag filtering, connection warnings, and persistence of the observed Sunshine capability version are included in the stable baseline.

Linux, Windows, and macOS packages are rebuilt from the tagged source. Protocol and persisted identity formats remain compatible with rc.10. Native packages are currently unsigned and must be verified with the attached manifests and SHA-256 files.
