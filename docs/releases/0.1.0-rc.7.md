# Sunshine Client 0.1.0-rc.7

本预发布版本统一 Windows、Linux 和 macOS Apple Silicon 的客户端交付方式：

- 每个平台只发布一个原生安装包；发行归档仅包含可执行文件、文档和校验元数据，不再附带 PowerShell、Shell 或 Python 安装包装脚本。
- 有交互终端的原生安装器会直接启动 `sunshine-client setup`；静默/无终端安装也保留已安装文件、身份和进度。该命令负责首次设置、未完成配对恢复、服务启停策略和首次连接验证；配对或验证失败时可再次运行。
- 原生 DEB、MSI、PKG 均注册低权限后台服务，CLI 与业务守护进程解耦；关闭终端或 SSH 不会停止服务，也不会产生第二个业务实例。
- 覆盖升级、修复和迁移保留设备身份、Manager 绑定、凭据、执行记录及原有服务启动意图，不要求重新配对。

macOS 发行包仅支持 Apple Silicon，未签名且未公证；Windows/Linux/macOS 的真实安装生命周期和 Sunshine 联调仍以对应平台 CI 及实机验收为准。
