# Sunshine Client 0.1.0-rc.8

本预发布版本收紧首次配置与 Windows 安装契约：

- Windows MSI 事务性追加安装目录到机器 PATH，修复和升级不重复添加，卸载移除产品拥有的条目；新终端可直接运行 `sunshine-client`。
- `setup` 拆分为配置、配对持久化、服务注册、启动策略、运行状态和连接六个顺序关卡。每一关都读取实际状态做后置验证，成功后才进入下一关。
- 请求连接验证但服务未运行时直接失败，不再以“跳过”掩盖失败并返回 `setup completed`。
- 错误响应新增 `error.step`、可读 `error.message`；服务管理命令失败时附带清理并限长的 `error.detail`，同时保留原有稳定 `error.code`、退出码、提交状态及事务 ID。
- 配对成功后重新读取受保护身份，只有持久状态明确为 active 才继续配置服务。

Windows、Linux 与 macOS Apple Silicon 的包仍为未签名、未公证的预发布产物；安装和覆盖升级保留设备身份、Manager 绑定、凭据及执行记录。
