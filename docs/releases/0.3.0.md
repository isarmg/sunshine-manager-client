# Sunshine Client 0.3.0

此版本与 Manager 的 `sunshine-management/3` 协议配套，协议包 `0.3.0`。Server 和 Client 必须一起更新；
当前 `/sunshine-client/v3/` 设备入口不接受 v2。管理员 API 仍使用 `/api/v2/`。

## 修复

- WSS 断开不再取消正在进行的本机操作；结果先持久化，Server 提交后发送包含指纹和摘要的收存回执。
- 回执丢失时补报原结果。已收存结果压缩为去重身份；未知意图保留到 Server 确认终结。
- 任务期限同时检查绝对时间、单调时间与包含休眠的运行时间；服务控制每个副作用步骤分别检查。
- Sunshine 重启使用 API 端口对应进程的新世代证明；响应为空或连接关闭不会导致重复 POST。
- 配置保存前保护原配置备份，再校验完整修订，保存后完整读回；读取不清除等待重启状态。
- 日志限制总读取量并保留尾部，使用稳定快照分页；扩大受保护记录以容纳合法结果。
- Manager HTTPS 与 WSS 使用相同系统信任来源。

## 升级

升级前核对未确认操作，停止 Client，并保留本机设置、凭据和执行记录。在 Manager 更换授权码后，
按 `pair replace` 流程重新配对。不要将 Windows SQLite 状态复制到 Unix，或将 Unix 文件状态复制到 Windows。

配置文件读回和进程重启仍不能证明实际串流运行效果。原生 Sunshine 接口没有原子条件写入，
最后读取和 POST 之间的本机并发编辑仍可能冲突。macOS 或无法读取本机进程证据时，重启保持未确认。

测试包含真实 Client 与隔离 TLS/WSS Manager 闭环、回执丢失、执行中断线及不重复写入，
不代替真实 Sunshine 的各平台服务与串流验收。当前源码版本不表示原生安装包已经发布。
