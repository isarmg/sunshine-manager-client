# Sunshine Client v0.1.0-rc.3

简化配对与 Windows 圆角托盘预发布版本。请配合 [Sunshine Manager Server v0.10.0](https://github.com/isarmg/sunshine-manager-server/releases/tag/v0.10.0) 使用。

## 下载与安装

- Windows 11 及以上 x86_64（最低 build 22000）：下载 `sunshine-client-0.1.0-rc.3-windows-x64.msi`，双击安装，从开始菜单打开 Sunshine Client，然后选择托盘“配对设置”。
- Ubuntu 24.04 x86_64：下载 `sunshine-client_0.1.0-rc.3_amd64.deb`，运行 `sudo apt install ./sunshine-client_0.1.0-rc.3_amd64.deb`，随后运行 `sudo sunshine-client-setup`。
- ZIP/tar.gz 用于命令行部署；普通 Windows 用户请选择 MSI。附件均提供 SHA-256 校验文件；安装包另附源码身份 manifest。

## 本次改动

- 只填写 Server 地址、配对码、本机 Sunshine 回环 IP、端口、账号和密码，不再手工填写设备标识或选择 CA 文件。
- 先校验本机 Sunshine，再完成设备注册；仅启动服务不会显示为配对成功。注册回执丢失时保留原身份安全重试。
- Windows 正常选择“停止服务并退出”会等待服务停止后退出；需要时请求 UAC，取消授权或停止失败则保留托盘。任务管理器强制结束不属于正常退出。
- Windows 服务为手动启动；已配对托盘在下次登录时请求启动服务。托盘菜单与配对窗口采用圆角。
- Linux 包名使用 GitHub 安全字符，Debian 内部版本仍使用 `0.1.0~rc3` 排序规则。

## 安全与限制

两端只接受系统已信任、名称匹配且有效的证书，不支持 TOFU、自签名确认或关闭 TLS 校验。Windows 服务使用计算机信任上下文；Sunshine 默认证书若未受信任或 SAN 不匹配回环 IP，配对会被拒绝，安装器不会修改证书。

不改变 Sunshine–Moonlight 串流，不安装 Sunshine，不开放额外入站端口，不提供任意脚本执行。Sunshine 凭据仅在本机受保护保存。默认不授权 Sunshine 重启；本机授权后仍须由 Manager 管理员逐次确认。

不支持覆盖旧安装或转换旧状态；卸载保留身份和执行记录，退役时须在 Manager 撤销设备。MSI 内部数字版本为 `0.1.0`，完整候选版本和源码 SHA 以 manifest / `--version` 为准。

Windows MSI **没有 Authenticode 签名**，可能出现 SmartScreen 提示；校验和不代替发布者签名。

## 验证范围

发行附件来自标签对应的成功 CI：Rust/严格 TLS 测试、双平台构建、MSI/DEB 原生安装、服务生命周期、拒绝覆盖和卸载保留状态。Windows 另检查圆角 UI 与正常退出停止服务。

原生安装 CI 基线为 Windows Server 2025 x86_64、Ubuntu 24.04 x86_64；不宣称已完成 Windows 11 桌面安装或本候选版本的真实 Sunshine 重启验收，因此保持预发布。
协议为 `sunshine-management/1`，固定适配官方 Sunshine `v2026.516.143833`，其他 Sunshine 版本会被拒绝。
