# Sunshine Client 0.2.0

- 协议升级为唯一的 `sunshine-management/2`，固定 Sunshine `v2026.914.233613`；旧协议、旧 Sunshine 版本和旧权限字段均不兼容。
- Manager 注册、身份检查与 WebSocket 连接只使用 `/sunshine-client/v2/*`，不尝试 v1 入口。
- Client 配对后直接启用 Sunshine 专用管理能力，不再询问或保存重启、应用命令及服务控制权限开关。
- 增加应用列表与基于内容引用/列表修订的保存、删除、关闭当前应用和受限 PNG 封面上传。
- 增加 Moonlight PIN、客户端启停/取消配对、分页脱敏 Sunshine 日志、诊断、虚拟输入状态和显示/Portal 维护。
- Windows 使用固定 `SunshineService`，Linux 使用固定 systemd `sunshine.service` 执行服务状态、启动、停止和重启；不接受远程服务名、路径或 Shell。
- 写入前持久化副作用意图，回执丢失后只核对应用、配对和服务事实；无法可靠观察的动作保持不确定且不会自动重做。
- 本地 HTTPS 夹具覆盖新增固定端点、应用索引映射、日志脱敏、证书与响应边界。

持久 Bootstrap 输入只接受当前字段。升级前需要按当前 `setup` 输入重新建立 v2 配置和 Manager 绑定；本版本不读取旧协议配置作为兼容路径。
