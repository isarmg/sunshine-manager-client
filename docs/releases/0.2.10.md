# sunshine-manager-client 0.2.10

- Manager WSS 连接只在明确带有设备凭据拒绝标识的 401 响应后停止重连；代理入口、临时故障及未标识的认证响应继续按退避策略重试。
- Windows 手动卸载会核验精确的 SunshineClient 服务身份，避免操作同名但不属于该安装的服务。
- Linux、Windows 的 Sunshine 服务控制使用有界等待，并核对最终运行状态；macOS 继续按当前能力声明不提供 Sunshine 服务控制。
- 当前管理协议为 sunshine-management/2，本机 Sunshine API 使用 HTTPS 回环地址。设备账户和执行日志格式保持当前 v2 合同。
- 通用 CLI、受保护文件读取与运行时依赖固定到 Foundation Client 0.9.16。

## 验证

Rust 测试、严格 Clippy、平台安装器单元测试通过。Linux、Windows、macOS 原生打包和服务安装验收由发行 tag 的 CI 执行；正式资产与校验和以该 CI 的 GitHub Release 为准。
