# Sunshine Manager Client 0.2.8

- 修正 Client 与 Manager 的实例授权码格式不一致：双方现在通过共享协议统一使用 Manager 签发的 36 位小写字母数字授权码。
- 交互式 Setup 在授权码输入后立即校验格式；错误输入返回明确的 `invalid_authorization_code`，不再要求填写完 Sunshine 凭据后返回笼统的 `invalid_configuration`。
- 延续 0.2.7 的可见授权码输入，避免 Windows 隐藏终端输入无法可靠粘贴而把授权码留给下一个提示；Sunshine 本机密码仍保持隐藏输入。
