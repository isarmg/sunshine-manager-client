# Sunshine Client 0.1.0-rc.11

This release candidate republishes the latest verified first-run setup behavior under a new immutable version. Pairing-state validation, service quiescing, installer flag filtering, connection warnings, and persistence of the observed Sunshine capability version are unchanged from rc.10.

Linux, Windows, and macOS packages are rebuilt from the tagged source. Protocol and persisted identity formats are unchanged; packages remain unsigned prerelease artifacts.
