# Sunshine Client 0.3.2

## 安装与设置

- 当前平台支持的 Sunshine 管理功能全部启用，不提供功能权限开关。
- Setup 只保留开机自启询问，默认 Yes，直接按 Enter 接受；无交互设置也默认启用。
- 配对成功后固定启动服务并验证连接，移除“立即运行”和“立即验证”的可选询问。
- Linux 首次安装默认启用系统级 systemd unit；未配对时等待设置，已有安装升级保留启停策略。
- Windows 默认注册 Automatic 的 SCM 系统服务，安装器移除功能选择页，默认保留配置与执行数据。
- systemd 的 enabled-runtime 不算持久开机自启，Setup 须读回持久策略后确认。
- 修正 Windows 管理适配器跨异步请求的借用方式，兼容本机 SQLite 备份状态。

沿用协议包 0.4.0、sunshine-management/3 和 Manager 0.12.1；无需重新配对或变更状态格式。
首次安装仍需填写 Manager 和本机 Sunshine 凭据；服务注册不代表已经配对或在线。

验证包含 Rust 设置策略回归、生成 DEB 的安装脚本、安装失败回滚及 Windows MSI 结构验证。
原生 systemd/SCM 安装生命周期由目标平台 CI 验收。本说明描述源码版本，不表示安装包已发布。
