# Sunshine Manager Client 0.2.4

本版本修复覆盖升级后旧账户状态阻断配对、且账户数据与重要执行数据错误分类不清的问题。

- Windows SQLite 与 Linux/macOS 文件后端统一识别 v1 配对资料，返回稳定错误码 `pairing_state_incompatible` 和明确的重新配对指引。
- `pair replace` 会先只读验证执行日志，再把旧 `identity.json` 安全归档为唯一名称；归档成功前绝不删除活动副本。
- 执行日志损坏、不兼容或不可读时返回 `important_state_incompatible`，并标记 `preserved=true`；不会因重新配对而删除或覆盖日志。
- 安装器继续覆盖程序、保留状态；兼容判断和恢复由共享 Rust 状态层执行，因此 Windows、Linux 与 macOS 行为一致。

升级后若看到 `pairing_state_incompatible`，请在 Manager 创建新授权码并运行 `sunshine-client pair replace --interactive`。不要重命名或删除整个状态目录。
