# Sunshine Client 0.1.0-rc.9

- 修复 Windows MSI 完成后以普通用户运行 Setup、导致受保护状态无法创建且配对未提交的问题。交互式 Setup 现在先检查管理员令牌，必要时通过 Windows `runas` 请求 UAC，等待提升后的进程完成后再退出。
- 安装器发起的 Setup 会保留结果窗口；UAC 取消或提权失败会显示明确的配置阶段错误。stdin 自动化不会丢失输入，而是要求调用方从管理员上下文运行。
- 人类可读错误改为最多三行：错误码与失败步骤、压缩后的单行原因、可直接执行的下一步。底层诊断详情限制为 240 个字符，JSON 自动化合同仍保留稳定字段。
- Windows、Linux 与 macOS 继续使用同一套六阶段 Setup 后置验证；安装、修复和卸载的机器 PATH 事务语义不变。

Windows x64、Ubuntu 24.04 x64 和 macOS Apple Silicon 原生产物由标签对应提交构建。产物未签名、未公证；安装前核对同页 SHA-256 与 manifest 中的源码提交。
