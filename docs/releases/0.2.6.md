# Sunshine Manager Client 0.2.6

- 修复 macOS 管理员运行 Setup 时可能把 `provisioning` 创建为 root 私有目录、导致 `_sunshineclient` 服务启动后立即权限失败的问题。
- macOS 升级安装会先验证旧 `provisioning` 子树的类型、属主、权限和硬链接，再把受影响的 root 状态安全迁移给服务账户；异常状态保持不变并终止安装。
- macOS 安装事务允许安全的 root 所有标记在失败后重试，并在成功时恢复原来已加载的 LaunchDaemon；root 创建但继承服务组的私有状态也可被迁移。
- 服务未能保持运行时，Setup 现在明确提示检查受保护的服务日志和结构化服务状态。
- 保留 0.2.5 的 Windows 不兼容账户状态准备流程以及既有协议、配置与执行日志兼容边界。
